# Kirby Codex Pet

A cheerful pink Kirby for Codex.

You can also try it in [codex-pets](https://codex-pets.net/#/pets/kirby).

## Files

- `pet.json`
- `spritesheet.webp`

## Install

Copy this folder into your Codex pets directory:

```text
%USERPROFILE%\.codex\pets\kirby
```

On WSL or Linux:

```text
~/.codex/pets/kirby
```

Then open Codex App and select Kirby in `Settings -> Appearance -> Pets`.
