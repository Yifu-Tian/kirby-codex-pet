# Kirby Codex Pet

A cheerful round pale pink digital pet for Codex.

## Files

- `pet.json`
- `spritesheet.webp`

## Install

Copy this folder to your Codex pets directory:

```text
%USERPROFILE%\.codex\pets\kirby
```

On WSL or Linux:

```text
~/.codex/pets/kirby
```

Then open Codex App and select Kirby in `Settings -> Appearance -> Pets`.
